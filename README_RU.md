# НомерЗнаток — Android-проект для тестовой сборки

В папке `www` лежат исходные файлы браузерной игры. GitHub Actions создаёт тестовый APK (debug).

## Сборка с телефона
1. Загрузите содержимое архива в свой GitHub-репозиторий (лучше отдельный репозиторий для Android).
2. Откройте вкладку Actions и разрешите запуск workflow, если GitHub спросит.
3. Запустите `Build test APK` через `Run workflow`.
4. Когда сборка завершится, откройте её и скачайте artifact `nomerznatok-debug-apk`.
5. Внутри ZIP будет `app-debug.apk` — это только тестовая сборка.

## Важно
Этот debug APK не предназначен для публикации в RuStore. Для публикации нужно создать подписанную release-сборку, сохранить ключ подписи в безопасности и протестировать приложение. Не публикуйте пароли или keystore в репозитории.
